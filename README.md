# Aybek & Asel — Свадебное приглашение · 06.11.2027

Интерактивный сайт-пригласительный на свадьбу **Айбека и Асель**.

- **Дата торжества**: 6 ноября 2027 года (Суббота, 17:00)
- **Место проведения**: Банкетный зал «Улуу Тоо» (*Uluu Too Banquet Hall*), г. Бишкек, ул. Сухэ-Батора, 5
- **Карта**: [Открыть в Google Maps](https://maps.app.goo.gl/ZCR7aL3gAXBYKn867)
- **Музыкальное сопровождение**: Мирбек Атабеков — «Күндөр жаңырат»
- **Языки интерфейса**: Русский (RU) · Кыргызча (KG) · English (EN)

## Структура проекта

- `index.html` — основная разметка пригласительного
- `styles.css` — минималистичный монохромный дизайн в стиле журнального эдиториала
- `app.js` — локализация `RU/KG/EN`, аудиоплеер, таймер обратного отсчёта, экспорт `.ics` в календарь, галерея невесты, анкета гостя (RSVP) и книга пожеланий
- `firebase-config.js` — настройки подключения к Firebase Cloud Firestore
- `photos/` — персональная свадебная фотосессия невесты Asel
- `audio/` — аудиодорожка «Мирбек Атабеков — Күндөр жаңырат»
